# Zepto E-commerce Data Analysis using SQL

## Project Overview
This project focuses on exploring and analyzing Zepto product and inventory data using SQL (PostgreSQL). It covers data exploration, basic cleaning, and business-oriented analysis to understand product pricing, discounts, availability, and inventory.

## Key Tasks Performed
- Explored product data and identified NULL values.
- Analyzed product categories and stock availability.
- Identified product names appearing across multiple SKUs.
- Removed products with zero MRP.
- Converted product prices from paise to rupees.
- Analyzed top discounted products.
- Identified high-priced products that are out of stock.
- Calculated estimated inventory revenue by category.
- Compared product prices and discount percentages.
- Calculated price per gram and categorized products by weight.
- Analyzed total inventory weight by category.

## SQL Concepts Used
- SELECT, WHERE, DISTINCT
- GROUP BY and HAVING
- Aggregate Functions (SUM, AVG, COUNT)
- ORDER BY and LIMIT
- CASE Statements
- Data Cleaning and Data Transformation
